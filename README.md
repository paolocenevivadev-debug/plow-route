# Plow Route

A storm-day route planner and service log for a snow plowing business. It runs as an installable web app: open the link on a phone, add it to the home screen, and it works offline.

- Plans the fastest order through the day's driveways, starting and ending at home
- Skip a stop for one storm and the route re-plans
- Time-stamped photo at each driveway as proof of service
- Storm history, season totals, and a one-file backup

All client data and photos stay on the phone. Nothing is uploaded to this repository or any server.

Forecast from the National Weather Service. Maps and drive times from OpenStreetMap contributors and the OSRM project. Address lookup from the US Census Bureau.
